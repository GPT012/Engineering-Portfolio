# GPT012 | Digital Product Portfolio

> Web applications, desktop software, and browser extensions by GPT012.

This repository brings together projects spanning content management, translation, and browser-based tools.

## Projects

### ConFluent translation tools
- **[ConFluent Mac](./ConFluent_Mac)**: Electron desktop app for voice input and translation.
- **[ConFluent Chrome](./ConFluent_Chrome)** and **[ConFluent Safari](./ConFluent_Safari)**: browser extensions for translating text entered on web pages.

### [CoefRessources](./coef-modern)
Content management and lead-tracking application built with Next.js 16, React 19, and Supabase.

### [Chess Animations](./Chess_Animations_Chrome)
Chrome extension project for chess move analysis and visual feedback on Chess.com.

## Technologies

- **Web**: Next.js, React, Supabase, and PostgreSQL.
- **Desktop**: Electron.
- **Browser extensions**: Chrome and Safari extension APIs, including Manifest V3.
