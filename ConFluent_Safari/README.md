# ConFluent Safari | Web Translation

> Translate text entered on supported web pages in Safari.

ConFluent Safari is a browser extension for translating text entered on web pages. Compatibility depends on the page and its input controls.

---

### 🚀 Key Features

- **Input translation**: Translates text entered in supported web page fields.
- **Popup controls**: Provides language selection and feature toggles.
- **Translation service**: Uses the Google Translate endpoint configured by the extension.

---

### 🛠️ Technical Specs

- **Manifest version**: `3`.
- **Content script**: Configured for all URLs and frames.
- **Declared host permissions**: `https://translate.googleapis.com/*` and `<all_urls>`.

---

### 🎨 Design & Experience
The popup provides controls for selecting a target language and toggling features.

---

### 📦 Installation

1.  Open the GitHub Repository.
2.  Enable Extensions in Safari Preferences.
3.  Load the extension from the `ConFluent_Beta` directory.
